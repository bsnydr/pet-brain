# Log a dog update

Goal: capture the update in the correct place, dated, newest on top, so it persists across sessions and is visible to both owners.

1. Classify the update and pick the destination (a Notion entry of the right Type, or the matching markdown file):
   - **Weight / measurement** → a `Weight` entry. Then re-check muzzle / harness / crate / bed sizing against the new size and flag anything outgrown.
   - **Behaviour / milestone / outing ("she did X")** → a `Behaviour` entry.
   - **Vaccine / med / vet visit / due date** → a `Vet` entry (set the due date if there is one).
   - **New static fact** (food, allergy, spay status, vet, insurance) → update the profile.
   - **Task / to-do** → a `Task` entry with a status.
2. Use today's date (`YYYY-MM-DD`). If the owner gives a different date, use that.
3. Keep entries short and factual. Do not duplicate an existing entry; update it instead.
4. If the update also changes the profile or a task, reflect it there too.
5. Never write an identifier (microchip, passport, insurance, tax, bank) into a shared or committed field. Those stay local per the privacy rule.
6. Confirm in one line what you logged and where.
